# scripts/02_hpc/probes — 一次性诊断探针

> 最后核对：2026-11-15 · commit 97d5e5d

**职责**：超算环境排障期间产生的一次性探针与冒烟脚本（MPI/yt/HDF5/链接/段错误等），**非稳定工具链**，不作为 API 复用。2026-10-26 由执行层测试子目录迁入此处，原因是它们依赖场景模块，留在执行层会触发分层护栏。

## 内容分组（26 个文件）

| 前缀 | 用途 |
|---|---|
| `_probe_*.py` | 单因素探测：dry-run、FLASH4、IMPI、链接、负载、MPI hello、配对、sed、Si、sim |
| `diag_*.py` | 健康/进程/安装日志/段错误/srun+yt 等诊断 |
| `try_yt*.py` | yt 版本兼容性试验 |
| `*.sh` | in-situ 冒烟与 srun 测试 |
| `sync_snb_assets.py` | SNB 资产同步辅助 |

## 约定

- 这些脚本可能引用已失效的临时路径，运行前须先读源码；不纳入 pytest 套件。
- 不放行 FLASH 派生源码，遵守 License §3 与 SNB 分享红线。
- 目录随仓库分发仅作排障记录，新增探针优先写入正式工具而非此处。
