# Gitee 私有仓库配置指南

本文档说明如何将 PhySimX Flash 项目配置为 Gitee 私有仓库，并管理访问权限。

---

## 1. 设置仓库为私有

### 步骤

1. 登录 Gitee，进入项目仓库页面
2. 点击 `设置`（右上角）
3. 在 `基本信息` 部分，找到 `仓库类型`
4. 勾选 `私有仓库`
5. 点击 `保存`

### 效果

- ✅ 只有你（所有者）和明确添加的成员可以访问
- ✅ 其他人无法查看、克隆或搜索到该仓库
- ✅ 仓库不会出现在 Gitee 的公开搜索结果中

---

## 2. 创建访问令牌（有时限）

访问令牌（Access Token）允许协作者在令牌有效期内访问仓库。令牌过期后自动失效。

### 步骤

1. 进入 Gitee 仓库页面
2. 点击 `设置` → `访问令牌`
3. 点击 `生成新令牌`
4. 填写令牌信息：
   - **令牌名称**: 如 `temp-access-2026-07`（建议包含过期日期）
   - **权限**: 选择以下之一：
     - `read_repository`: 只读权限（可以克隆和拉取，但不能推送）
     - `write_repository`: 读写权限（可以推送代码）
   - **过期时间**: 设置令牌有效期（如 `2026-07-10`，7 天后过期）
5. 点击 `提交`
6. **复制令牌值**（只显示一次！）

### 分享令牌给协作者

将以下命令发送给协作者：

```bash
# 使用令牌克隆仓库
git clone https://oauth2:令牌@gitee.com/你的用户名/physimx_flash.git

# 或者，如果已经克隆了仓库，可以修改远程 URL
git remote set-url origin https://oauth2:令牌@gitee.com/你的用户名/physimx_flash.git
```

### 注意事项

- ⚠️ **令牌值只显示一次**，请妥善保存
- ⚠️ **令牌过期后自动失效**，需要重新生成
- ⚠️ **不要将令牌提交到代码仓库**，令牌应该只存在于协作者本地

---

## 3. 管理协作者

如果需要长期协作，可以添加协作者到仓库（而不是每次都生成令牌）。

### 步骤

1. 进入 Gitee 仓库页面
2. 点击 `设置` → `成员管理`
3. 点击 `添加成员`
4. 输入协作者的 Gitee 用户名或邮箱
5. 选择角色权限：

| 角色 | 权限说明 |
|------|----------|
| **Guest（访客）** | 只能查看代码，不能推送 |
| **Reporter（报告者）** | 可以查看和创建 Issue、PR |
| **Developer（开发者）** | 可以推送代码、创建分支 |
| **Maintainer（维护者）** | 可以管理分支、合并 PR、管理 Issues |
| **Owner（所有者）** | 完全控制（谨慎分配） |

6. 点击 `添加`

### 角色建议

- **核心开发者**: `Developer` 或 `Maintainer`
- **临时协作者**: 使用访问令牌（有时限）
- **外部贡献者**: `Reporter`（只能提交 PR，不能直接推送）

---

## 4. 访问令牌管理

### 查看现有令牌

1. 进入 Gitee 仓库页面
2. 点击 `设置` → `访问令牌`
3. 查看所有活跃的令牌

### 撤销令牌

1. 在 `访问令牌` 页面，找到要撤销的令牌
2. 点击 `撤销`
3. 确认撤销

**效果**: 令牌立即失效，持有该令牌的人无法再访问仓库。

### 延长令牌有效期

Gitee 不支持直接延长令牌有效期。需要：

1. 撤销旧令牌
2. 生成新令牌（设置新的过期时间）
3. 将新令牌分享给协作者

---

## 5. 安全最佳实践

### ✅ 推荐做法

1. **使用短过期时间**: 如 7 天或 30 天，避免永久令牌
2. **最小权限原则**: 只授予必要的权限（如只读令牌用于 CI/CD）
3. **定期轮换令牌**: 即使没有过期，也建议定期重新生成令牌
4. **审计日志**: 定期检查 Gitee 的访问日志，查看是否有异常访问

### ❌ 避免的做法

1. **不要将令牌提交到代码仓库**
2. **不要通过不安全的渠道分享令牌**（如邮件、聊天工具）
3. **不要使用永久令牌**（除非绝对必要）
4. **不要忽略令牌过期提醒**（Gitee 会在令牌快过期时发送提醒）

---

## 6. 常见问题

### Q1: 令牌过期后怎么办？

**A**: 重新生成新令牌，并将新令牌分享给协作者。

### Q2: 如何撤销协作者的访问权限？

**A**: 
- 如果使用访问令牌：撤销该令牌
- 如果添加了成员：在 `成员管理` 中移除该成员

### Q3: 协作者忘记令牌怎么办？

**A**: 重新生成新令牌，并将新令牌分享给协作者。（不要通过不安全的渠道发送旧令牌）

### Q4: 如何查看谁访问了仓库？

**A**: Gitee 企业版支持访问日志。免费版可能不支持此功能。
