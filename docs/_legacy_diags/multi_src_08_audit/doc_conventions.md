# Multi{1D}++ 数据格式总览

> 本文件是《MultiEOSOP格式说明.md》的**写作辅助**：由主理人在派遣写手前固化术语与全局约定，
> 供各章写手引用，避免术语与措辞漂移。**不直接进入交付物**（前置部分由写手 00_front.md 承载）。

## 术语定稿（全文强制统一）

| 术语 | 定义 | 禁用替代 |
|---|---|---|
| 格式族（family） | 一组共享同一字节布局与单位体系的文件类型 | 格式类、格式种类 |
| 表号（table number） | 文件头部的整数标识，编码材料与表型 | 编号、ID |
| 表型（table type） | 表号低 3 位，标定物理含义（301/304/305/…） | 类型、种类 |
| 反演（inversion） | 由 `P(ρ,T), E(ρ,T)` 求 `P(ρ,E), T(ρ,E)` | 逆转、求逆 |
| 群边界（group boundary） | 多群不透明度各能群的频率/能量分界点 | 能界、边界 |
| 能群（energy group） | 群边界划分出的一个频率区间 | 频群 |
| Rosseland 平均 | 以 `1/κ_R = ∫(1/κ_ν)(∂B_ν/∂T)dν / ∫(∂B_ν/∂T)dν` 加权的平均不透明度 | 罗斯兰 |
| Planck 平均 | 以 `B_ν` 为权重的平均不透明度（吸收） | 普朗克 |
| EPS | 归一化发射率表（normalized emissivity） | — |
| Zeff | 平均电离度（平均每个离子的自由电子数） | 有效电荷 |
| NLTE | 非局部热动平衡 | 非平衡 |
| u 网格 | 无量纲光子能量网格 `u = hν/kT` | 无量纲网格 |
| T-major | 温度外层、密度内层的存储顺序 | 温度优先 |
| 定宽格式 | 字段按固定列宽排布，无分隔符 | 固定格式 |
| 自由格式 | 字段以空白分隔，无固定列宽 | 自由输出 |
| matter++ | Multi1D++ 便携版中的材料数据目录 | matter |
| 上游源 | `src/Multi1D++Portable20241128/` 下随包发布的文档与数据文件 | — |

## 记号定稿

| 记号 | 含义 | 出处约定 |
|---|---|---|
| `nr` / `nt` / `ng` | **文件内**声明的密点数 / 温度点数 / 群数（小写，取自文件头实测） | 实测 |
| `NR` / `NT` / `NG` | **程序内**维数上限或用户请求维数（大写，取自手册/namelist） | 手册 |
| `ρ` | 密度（`g/cm3`） | — |
| `T` | 温度（各族原生单位不同，**必须逐次标注**） | — |
| `P` | 压强 | — |
| `E` | 比内能 | — |
| `e0` | 零温（冷）能量 | — |
| `κ_R` / `κ_P` | Rosseland 平均 / Planck 平均不透明度（`cm2/g`） | — |
| `Z̄` | 平均电离度 | — |
| `<Z>` / `<A>` | 平均原子序数 / 平均原子量 | — |

## 单位书写规范（全文强制）

- 原生单位用**等宽体**：`g/cm3`、`Mbar`、`eV`、`keV`、`cm2/g`、`dyne/cm2`、`erg/g`、`J/cm3`、`J/g`、`µm/ns`。
- 物理量首次出现给三元组：`物理量（格式内原生单位 → MULTI 内部单位 → SI）`。
- 换算**必须写完整推导链**，例如 `1 GPa = 1e9 dyne/cm2 = 1e3 bar = 1e-2 Mbar`。
- **禁止**只给数字不给链；**禁止**跨族复用单位结论。

## 溯源六级标注（全文强制）

| 记号 | 含义 | 必附信息 |
|---|---|---|
| `[S-L1]` | 上游手册/格式说明**明文规定** | 手册文件名 + 节名 |
| `[S-L2]` | **数据文件自身内嵌声明** | 相对路径 + 原文片段 |
| `[S-L3]` | **程序约定默认**（文件未声明时） | 约定来源文件 |
| `[S-L4]` | **推导** | 完整量纲链 |
| `[S-UNK]` | **本地无依据**，标 unknown，不猜测 | 说明"为什么无法确定" |
| `[S-WEB]` | **网络核验** | URL + 访问日期 |

**冲突处理**：本地与网络冲突时**以本地为准**，并显式记录冲突（见 `.workbuddy/tmp/web_verify.md`）。

## 路径约定

全文文件名一律用**相对路径**，相对根 `src/Multi1D++Portable20241128/`。
例：`matter++/mat_Al-1.0/AL_eos`、`doc/SNOP.MANUAL`、`matter++/Readme.txt`。
