## 一、结论（推翻此前两处错误）

### 记录序（每个能量群一条完整记录）

```
文件级表头 (60 字符 = 4 × 15)
  [0:15]   表号（6-7 位，如 27003003 / 79003000 / 1400003）
  [15:30]  类别名 + ' M'（'PLANCK M' / 'ROSSELAND M' / 'EPS M'；ZEFF 无 ' M'）
  [30:45]  NR（密度网格点数）
  [45:60]  NT（温度网格点数）

随后 K 个能量群，每群：
  2 值行 (30 字符 = 2 × 15) : 能量带上下界 [E_lo, E_hi]（eV）
  4 值行 (60 字符 = 4 × 15) : 该群的记录骨架
      [0:15]  能量带下界 E_lo（与上一行重复）
      [15:30] 能量带上界 E_hi（与上一行重复）
      [30:45] NR
      [45:60] NT
  数据区 : log10(ρ[NR]) | log10(T[NT]) | log10(κ[NR·NT])
           共 NR + NT + NR·NT 个值，每行 4 × 15 = 60 字符
```

### 每群值数 = NR + NT + NR·NT（不含重复的 4 字段骨架）

实测 `AU_op03p`（NR=20, NT=20）：每群体区 **恰好 440** = 20 + 20 + 400 ✓
- 值 0–19：`log10(ρ)`，−6.0 → 2.0（20 点，严格递增）
- 值 20–39：`log10(T)`，0.0 → 5.0（20 点，严格递增）
- 值 40–439：`log10(κ)`，400 点

### 走向：外层 T、内层 ρ ⇒ **密度变化最快**

由官方写出器 `matlab/outputMULTIOpacity.m:58-68` 明文：
```matlab
for i=1:nt
  for j=1:nr
    fprintf(fout, '%15.7e', log10(kappa((i-1)*nr + j)));
```
索引 = `(i_T − 1)·NR + j_ρ`。与 `.sesame` 的走向**一致**。
独立实测印证：数据区"凹陷间隔"恒为 **NT = 20**。

## 三、群数 K 的判定（两种编码并存）

1. **由文件名后缀**：`*20*` → 20 群；`*100*` → **100 群**
   - `Gd20PLANCK`(20) vs `Gd100PLANCK`(100)，**表号同为 27003000**
   - `CHSi1_mopp`(20) vs `CHSi1_mopp100`(100)，**表号同为 1400003**，字节数恰好 ×5
2. **由文件本身**：数 30 字符行（2 值行）的个数即 K。**解析器应以此为准**，
   文件名后缀仅作交叉校验。

⚠️ **必须由文件本身判定 K，不可硬编码文件名后缀** —— `opbe` 是反例（命名为 `opbe` 无群数
提示，实际 80 群且末群截断）。

## 六、解析器（定稿版）

```python
def read_multigroup_opacity(path):
    """读无扩展名 PLANCK/ROSSELAND/EPS 多群不透明度表。
    返回 (table_no, kind, NR, NT, [ {band:(lo,hi), log10rho, log10T, log10kappa} ])"""
    raw = open(path, 'rb').read().replace(b'\r\n', b'\n')
    L = [l.decode('latin-1') for l in raw.split(b'\n') if l.strip()]

    hdr = L[0]
    table = hdr[0:15].strip()
    kind  = hdr[15:30].strip()          # 'PLANCK M' / 'ZEFF' 等
    NR = int(float(hdr[30:45]))
    NT = int(float(hdr[45:60]))

    # 每个群以 30 字符（2 值）行为界
    marks = [i for i, l in enumerate(L) if len(l) == 30]
    groups = []
    for k, s in enumerate(marks):
        # 骨架行：4 值，前两值与 band 重复
        skel = L[s + 1]
        assert abs(float(skel[0:15]) - float(L[s][0:15])) < 1e-9
        band = (float(L[s][0:15]), float(L[s][15:30]))

        e = marks[k + 1] - 2 if k + 1 < len(marks) else len(L)   # 减去下一群的 band+skel
        vals = []
        for l in L[s + 2:e]:
            for j in range(0, len(l) - 14, 15):
                vals.append(float(l[j:j + 15]))
        n = NR + NT + NR * NT
        if len(vals) != n:                 # 末群可能截断（如 opbe）
            trunc = True
        groups.append({
            'band': band,
            'log10rho':  vals[0:NR],
            'log10T':    vals[NR:NR + NT],
            'log10kappa': vals[NR + NT:NR + NT + NR * NT],
            'complete':  len(vals) == n,
        })
    return table, kind, NR, NT, groups
```

⚠️ **三个陷阱**：
1. 必须**排除含类别名的行**（文件级表头 60 字符）后再找 30 字符行，
   否则误判。
2. 每群的**骨架行（4 值）与 band 行（2 值）前两值重复**，计数时不要把骨架行算进数据区。
3. **末群可能截断**（`opbe` 第 80 群仅 884 值），解析器须标记 `complete=False`
   而非断言崩溃。
