# 03 — 编译与依赖清单

> 本文件只列**需要什么、改动的性质**，不含任何源码片段。

---

## 1. 编译前置依赖

| 依赖 | 说明 |
|---|---|
| FLASH 4.8 源码树 | 含 `./setup` 与 `./source/` |
| MPI 编译器 | `mpif90`（本机 WSL 用 mpich；超算用 oneAPI/MPICH） |
| HDF5 | `+hdf5typeio` 需要 |
| HYPRE（可选） | 隐式扩散求解器；无则用内置求解器 |
| Python 3 + `numpy/h5py/matplotlib` | 仅分析与绘图需要 |

---

## 2. 树级补丁（**必须先做**）

除场景覆盖文件外，FLASH 树本身有两处需要打补丁，否则 SNB 场景编译不过：

| 补丁 | 目标文件 | 改动的性质 |
|---|---|---|
| A | 扩散步长计算文件（`Diffuse` 模块下） | 让电导按 `aniso` 开关**分流到对应签名的重载**：各向异性走 `anisoFullState`，各向同性走标量版本 |
| B | 流体通量文件（`hy_uhd` 模块下） | 同上：`Conductivity` 按 `aniso` 分流 |

**铁律**：若遇到"泛型不匹配"，**改调用方，不要改接口**。

---

## 3. 场景覆盖文件的两处必需改动

| 现象 | 改动的性质 |
|---|---|
| `Cannot open module file 'hy_uhd_slopelimiters.mod'` | 覆盖文件引用的模块名与树内不一致（树内实际名少了 `uhd_` 前缀）→ 改成树内真实模块名。涉及 2 个重构文件与 2 个 Riemann/Driv 文件。 |
| 编译报某长表达式续行错误 | 覆盖文件缺少 Fortran 续行符 → 按 Fortran 规则补齐（不要改动表达式本身）。 |

**教训**：`src/<作者包>/` 是**未打补丁的原始包源**，直接复制必然踩上面两条。
应以**已知可用的工作副本**为准。

---

## 4. 场景 Makefile

必须把多群能量权重模块列入 Simulation 段：

```
Simulation += Simulation_data.o mgd_qesh.o
```

漏写会在**链接期**失败（而不是编译期）。

---

## 5. Config 必需项

| 项 | 内容 |
|---|---|
| `REQUIRES Driver` / `physics/Hydro` | 基础 |
| `USESETUPVARS ThreeT` + `IF ThreeT` 块 | 3T 条件依赖 |
| `REQUESTS physics/Diffuse/DiffuseMain/Unsplit` | 隐式扩散 |
| `REQUESTS physics/materialProperties/Conductivity/ConductivityMain/SpitzerHighZ` | 电导 |
| `REQUESTS physics/sourceTerms/Heatexchange/HeatexchangeMain/Spitzer` | 热交换 |
| `DATAFILES <表名>.cn4` | 表随 setup 复制到 objdir |
| `VARIABLE <诊断量>` | SNB 诊断用的额外解向量（**数量不受 12 项限制**，那是 `plot_var` 的限制） |

---

## 6. 编译流程与判据

```bash
cd <TREE> && ./setup -auto <SimName> <flags> -objdir=<OBJDIR>
cd <OBJDIR>
# 先单独编模块, 规避 -j 并行竞态 (易错点)
make Conductivity_interface.o Conductivity_fullState.o mgd_qesh.o
make -j4 > make.log 2>&1
test -x ./flash4 && echo BUILD_OK
```

| 判据 | 说明 |
|---|---|
| ✅ `BUILD_OK` | `flash4` 可执行 |
| ❌ 判定方式 | 用**退出码**或 `test -x flash4`；**不要** `grep error`（源文件名含 `error` 会误报） |

---

## 7. 常见编译错误速查

| 错误 | 原因 | 处置 |
|---|---|---|
| `Cannot open module file 'xxx.mod'` | 模块名不符 / 模块未先编译 | 改模块名；或先单独 `make` 该模块 |
| `There is no specific subroutine for the generic 'Conductivity'` | 泛型签名不匹配 | 按 `aniso` 分流（补丁 A/B） |
| `Unclassifiable statement` | 长表达式缺续行符 | 补 `&` |
| `undefined reference to mgd_qesh_` | Makefile 漏 `mgd_qesh.o` | 补 Makefile |
| `SETUPERROR: ... parallelIO` | `-nofbs` 与 `+serialIO` 冲突 | 去掉 `+serialIO` |

---

## 8. 旧 `.mod` 缓存导致"改了却没生效"

修改接口后若报错不变，**删除 objdir 里的 `*.mod` 再重编**（强重编）。
同理，更换覆盖文件后建议 `rm -rf <OBJDIR>` 重新 setup。
