# 02 — 端到端流程文档

> 从零到出图的完整流程。每一步都给出**输入 / 输出 / 判据**，
> 便于在无人值守时判断是否该继续。

---

## 0. 流程总览

```
[0] 前置检查  →  [1] 准备单元  →  [2] setup  →  [3] make
      ↓
[4] 短时验证 (tmax≈1e-11)  ──失败──→ 查 docs/05_坑位清单.md
      ↓ 通过
[5] 正式运行 (dtmax=2e-14)  →  [6] 收集输出  →  [7] 绘图 + 定量  →  [8] 分享前自检
```

---

## 1. 前置检查（30 秒）

| 检查 | 命令 / 判据 |
|---|---|
| FLASH 树可用 | 存在 `./setup` 与 `./source/` |
| 树级补丁就位 | 两个补丁文件存在（见 `03_编译与依赖.md`） |
| EOS/opacity 表齐备 | 每个物种一张 `.cn4`，**群数一致** |
| 表温度下限覆盖初值 | 冷启动（≈290 K ≈ 0.025 eV）需表下限 ≤ 0.01 eV |
| 覆盖 F90 齐备 | 9 个文件（见 `01_设置方法.md` §4） |
| 磁盘/WSL 空间 | 1024 格 × 17 帧 chk ≈ 12 MB/腿（plt 另计） |

```bash
python flash/scenarios/private/SNB/SNB/scripts/run_snb_scene.py --check-only
```

## 2. 准备单元

把下列内容放进 `<TREE>/source/Simulation/SimulationMain/<SimName>/`：

```
Config                      ← 依赖声明 + 额外 VARIABLE 注册
Makefile                    ← Simulation += Simulation_data.o mgd_qesh.o
Simulation_data.F90         ← 模块变量声明
Simulation_init.F90         ← 读取运行时参数
Simulation_initBlock.F90    ← 初始条件（分层/示踪）
<9 个 SNB 覆盖 F90>          ← 若你已有作者包；否则无法启用 SNB
*.cn4                       ← EOS/opacity 表
```

> ⚠️ 覆盖文件放错位置会**静默不生效**（FLASH 不报错，只是没用上）。
> 判定方法：看 `objdir` 里该文件的软链接指向 `SimulationMain/<SimName>/` 而不是 `physics/`。

---

## 3. setup

```bash
cd <TREE> && rm -rf <OBJDIR>
./setup -auto <SimName> -1d +cartesian +ug -nxb=128 +hdf5typeio \
        species=... +mtmmmt +laser +uhd3t +mgd mgd_meshgroups=10 -objdir=<OBJDIR>
```

**判据**：`<OBJDIR>` 目录被创建。

**常见失败**：
- 物种数不匹配 → 检查 `species=` 与 `Config`；
- `mgd_meshgroups` 与 `rt_mgdNumGroups` 不一致 → 改 par 或 setup；
- `-nofbs` 与 `+serialIO` 冲突。

---

## 4. make

```bash
cd <OBJDIR>
make Conductivity_interface.o Conductivity_fullState.o mgd_qesh.o   # 先单独编模块, 避 -j 竞态
make -j4 > make.log 2>&1
test -x ./flash4 && echo BUILD_OK
```

**判据**：`./flash4` 存在。

> ⚠️ 判定**不要用 `grep -i error`**：源文件名里含 `error` 会造成误报。
> 用 `make 的退出码` 或 `test -x flash4`。

---

## 5. 短时验证（**必做**）

```bash
# tmax 极小, 只验证能否启动
sed -i 's/^tmax.*/tmax = 1.0e-11/' flash.par
mpiexec -n 8 ./flash4 > run.log 2>&1
```

**通过判据（全部满足）**：

| 判据 | 期望 |
|---|---|
| 退出信息 | `exiting: reached max SimTime` |
| chk 帧数 | ≥ 2（含 `_0000`） |
| 起始步长 | 不坍缩到 `dtmin` |
| 中止信息 | **无** `Negative 3T internal energy` |
| EOS 警告 | `eos_nr WARN` 行数应很少 |

**失败 → 见 `05_坑位清单.md`**：

| 症状 | 首查 |
|---|---|
| `Negative 3T internal energy` | `dtmax` 是否 ≤ 2e-14（P2） |
| 步长坍缩到 `dtmin` | 同上；再看界面是否过锐（P3） |
| 辐射不涨（`trad` 冻结） | 辐射调用是否被注释（P5） |
| 质量/能量不守恒 | 限流器是否被设为"无限流"（P1） |

---

## 6. 正式运行

```bash
# ★ dtmax 必须收紧
sed -i 's/^dtmax.*/dtmax = 2.0e-14/' flash.par
# chk 密集, plt 稀疏
grep -q '^checkpointFileIntervalTime' flash.par || \
  echo 'checkpointFileIntervalTime = 5.0e-11' >> flash.par
sed -i 's/^plotFileIntervalTime.*/plotFileIntervalTime = 4.0e-10/' flash.par
# 关掉 step 触发 (与 time 是 OR 双触发)
sed -i 's/^\(plotFileIntervalStep.*\)/#\1/' flash.par
sed -i 's/^\(checkpointFileIntervalStep.*\)/#\1/' flash.par

mpiexec -n 8 ./flash4 > run.log 2>&1
```

**耗时参考**（1D，1024 格，dtmax=2e-14，tmax=0.8 ns）：

| 配置 | 步数 | 墙钟 | 速率 |
|---|---|---|---|
| 限流 SH，辐射开 | ≈4.0 万 | ≈970 s | ≈40 步/s |
| 限流 SH，辐射关 | ≈4.0 万 | ≈460 s | ≈85 步/s |
| SNB，辐射开 | ≈4.0 万 | ≈1800 s | ≈23 步/s |
| SNB，辐射关 | ≈4.0 万 | ≈1200 s | ≈33 步/s |

> 关辐射可省 **2.5×** 机时；SNB 比限流 SH 慢约 **1.6–1.8×**。

## 7. 收集输出

**铁律：先校验、后删除。**

```bash
OUT=/mnt/<...>/flash_output/<tag>
mkdir -p "$OUT"
cp -f ./<basenm>* ./<log_file> ./run.log "$OUT"/
n=$(ls "$OUT"/<basenm>*hdf5_chk_* | wc -l)
[ "$n" -gt 0 ] && rm -f ./<basenm>* || echo "收集失败, 保留现场"
```

> ⚠️ **不要**写 `cp ... 2>/dev/null; rm -f ...` —— 复制失败时会**静默丢数据**。

## 8. 绘图与定量

数据源优先 **chk**。

| 图 | 说明 |
|---|---|
| 时空彩图 | 每物理量一张；线性 t[ns] / 线性 x[µm]；`nele` 用对数色标 |
| 剖面系列图 | 在共同时间窗内均取 10 个时刻，取最近真实帧（不插值） |

物理量：`tele[eV]` / `tion[eV]` / `trad[eV]` / `dens[g/cm³]` / `pele[Mbar]` / `pres[Mbar]` / `nele[cm⁻³]`

单位换算：`K → eV` 除以 `1.1604519e4`；`erg/cm³ → Mbar` 乘以 `1e-12`；
`nele` 离线推导 `Ye·6.02e23·ρ`（避免两腿口径不一致）。

**定量量**：
- 烧蚀面 `x_a`：ρ 剖面最陡处；
- 致密面密度 `M_dense = ∫ρdx`（ρ ≥ 0.5ρ_solid）；
- 烧蚀速率 `Ṁ = −dM_dense/dt`，取**后 30% 时段**线性拟合（避开上升沿前的静默期）。

```bash
python flash/scenarios/private/SNB/SNB/scripts/run_snb_scene.py --analyze <outdir>
```
