# 01 — SNB 场景设置方法

> 本文只讲**怎么设置**，不讲实现。所有 F90 相关内容一律只列**文件名 + 需改动的性质**，
> 不给出源码片段（分享规则见 `06_分享与保密规则.md`）。

---

## 1. 前提与依赖

| 前提 | 要求 | 为什么 |
|---|---|---|
| 求解器 | **3T**（`+uhd3t`） | SNB 作用在电子温度方程上，需要独立的 `tele` 场 |
| 多物种 | `+mtmmmt` | 分层/示踪靶需要 |
| 激光 | `+laser` | 烧蚀驱动 |
| 辐射 | `+mgd mgd_meshgroups=N` | 与 `rt_mgdNumGroups=N` 必须一致 |
| 网格 | **必须 `+ug`（均匀网格）** | SNB 跨平均自由程积分，AMR 粗细界面会破坏守恒 |
| EOS/opacity 表 | 全体物种**群数一致** | 不一致 FLASH 直接 abort |
| 表温度下限 | 须覆盖初值温度 | 冷启动时表外会被钳位，状态不一致 |

### `+ug` 下的网格规则（易错）

- `+ug` **忽略** par 里的 `nblockx` / `lrefine_*`；
- **一块一进程** → `mpiexec -n` 必须**严格等于** par 的 `iProcs`；
- 分辨率有三条路径：

| 路径 | 做法 | 总格数 |
|---|---|---|
| ① 固定块 | `-nxb=N`，`iProcs` 不变 | `iProcs × N` |
| ② 非固定块 | 显式 `-nofbs` + par `iGridSize=M` | `M`（与核数解耦） |
| ③ 核数 | `iProcs` 本身 | `iProcs × nxb` |

> ⚠️ 只"不给 `-nxb`"进不了非固定块模式：FLASH 默认仍定义 `FIXEDBLOCKSIZE` 且 `NXB=8`，
> `iGridSize` 被静默忽略。必须**显式** `-nofbs`。
> 且 `-nofbs` 会强制并行 HDF5 IO，与 `+serialIO` / `parallelIO=False` 冲突。

## 2. setup 命令

```bash
./setup -auto <SimName> -1d +cartesian +ug -nxb=<NXB> +hdf5typeio \
        species=<sp1>,<sp2>,... +mtmmmt +laser +uhd3t +mgd mgd_meshgroups=<NG> \
        -objdir=<OBJDIR>
```

参考量级（1D、域 300 µm、dx≈0.29 µm）：`-nxb=128` × `iProcs=8` = 1024 格。

> `species` 个数 = Config 里注册的物种数，顺序即 FLASH 物种常量顺序。

## 3. par 参数清单（按功能分组）

### 3.1 几何与物种

| 参数 | 说明 |
|---|---|
| `xmin` / `xmax` | 域边界（CGS，cm） |
| `geometry` | `"cartesian"` |
| `sim_rho<Sp>` / `sim_tele<Sp>` / `sim_tion<Sp>` / `sim_trad<Sp>` | 各物种初始密度/温度 |
| `ms_<sp>A` / `ms_<sp>Z` / `ms_<sp>ZMin` | 原子量 / 电荷 / 最小 Z |
| `eos_<sp>EosType` = `"eos_tab"`、`eos_<sp>SubType` = `"ionmix4"`、`eos_<sp>TableFile` | EOS 表绑定 |
| `op_<sp>Absorb` = `"op_tabpa"`、`op_<sp>Emiss` = `"op_tabpe"`、`op_<sp>Trans` = `"op_tabro"`、`op_<sp>FileType` = `"ionmix4"`、`op_<sp>FileName` | 不透明度表绑定 |
| `smallt` / `smallX` | 温度/组分的下限（避免除零） |

### 3.2 激光（多段梯形）

| 参数 | 说明 |
|---|---|
| `ed_numberOfPulses` / `ed_numberOfBeams` | 脉冲数 / 束数 |
| `ed_numberOfSections_1` | 第 1 脉冲的段数 |
| `ed_time_1_i` / `ed_power_1_i` | 第 i 段的时间 [s] / 功率 [W] |
| `ed_lensX_1` / `ed_targetX_1` | 透镜位置 / 靶位置（决定入射方向：由 lens 指向 target） |
| `ed_wavelength_1` | 波长 [µm] |
| `ed_crossSectionFunctionType_1` | `"uniform"` / `"gaussian1D"` |
| `ed_numberOfRays_1` / `ed_gridType_1` / `ed_gridnRadialTics_1` | 光线数与网格 |

> 典型 4 段梯形（0 → 0.2 ns 上升 → 0.99 ns 平台 → 1.0 ns 归零）：
> `ed_time_1_*` = 0 / 0.2e-9 / 0.99e-9 / 1.0e-9，
> `ed_power_1_*` = 0 / P / P / 0。

### 3.3 辐射（MGD 多群）

| 参数 | 说明 |
|---|---|
| `rt_useMGD` | 开/关 MGD 多群辐射输运 |
| `rt_mgdNumGroups` | **必须 == setup 的 `mgd_meshgroups`** |
| `rt_mgdBounds_1..N+1` | N 群需要 **N+1** 个能量边界 [eV] |
| `rt_mgdFlMode` / `rt_mgdFlCoef` | 辐射通量限制器 |
| `rt_mgd{Xl,Xr}BoundaryType` | 边界类型（如 `"vacuum"`） |
| `useOpacity` | 不透明度开关 |
| `useRadTrans` | 辐射输运总开关 |
| `op_tableEnergyTolerance` | 查表能量容差 |

### 3.4 电子热传导（SNB 相关核心）

| 参数 | 推荐值 | 说明 |
|---|---|---|
| `useDiffuse` / `useDIffuseTherm` / `useConductivity` | `.true.` | 打开热传导框架 |
| `diff_useEleCond` | `.true.` | 电子传导 |
| `diff_eleFlMode` | `"fl_none"` | ★ 项目约定默认。**实测该键在 SNB 电子路径上是 no-op**（`fl_none` 与 `fl_harmonic` 逐位相同）—— 见 `05_坑位清单.md` P1 更正块 |
| `diff_eleFlCoef` | `0.06` | 限流系数（对**离子腿**与 `FLLM_VAR` 诊断量生效） |
| `diff_thetaImplct` | `1.0` | 全隐式 |
| `diff_anisoCondForEle` | `.false.` | 各向同性 |
| `diff_ele{Xl,Xr}BoundaryType` | `"neumann"` | 电子传导边界 |
| **`gr_hypreUseFloor`** | **`.false.`** | ★★★ **承重键**：FLASH 默认 `.true.` → SNB 多群解失真 → 崩塌。作者原版 par 亦为 `.false.` |
| `dt_diff_factor` | `1.0e100` | **关掉扩散步长限制**（SNB 下必须） |

### 3.5 热交换与时间积分

| 参数 | 推荐值 | 说明 |
|---|---|---|
| `useHeatexchange` | `.true.` | 电子-离子耦合 |
| `hx_dtFactor` | `1.0e100` | 关掉热交换步长限制 |
| `rt_dtFactor` | `1.0e100` | 关掉辐射步长限制 |
| `tstep_change_factor` | `1.10` | 步长增长因子 |
| `cfl` | `0.2` | |
| `dtinit` / `dtmin` | `1.0e-15` / `1.0e-16` | |
| **`dtmax`** | **`2.0e-14`** | ★ `2e-12` 会启动失稳（见坑位 P2） |
| `tmax` | 按脉冲定（如 `0.8e-9`） | |
| `nend` | 大值（如 `1.0e8`） | |

### 3.6 输出（建议以 **chk** 为主）

| 参数 | 建议 | 说明 |
|---|---|---|
| `basenm` / `log_file` | 每腿唯一 | 避免多腿输出互相覆盖 |
| `checkpointFileIntervalTime` | 如 `5.0e-11` | ★ **chk 是推荐绘图数据源** |
| `plotFileIntervalTime` | 稀疏（如 `4.0e-10`） | plt 仅作健全性检查 |
| `plotFileIntervalStep` / `checkpointFileIntervalStep` | **不写** | 与 Time 是 **OR 双触发**，不写才能只按时间触发 |
| `plot_var_1..12` | ≤ **12** 项 | `IO/IOMain/Config` 只声明 `plot_var_1..12`，第 13 项起**静默忽略** |

> **为什么优先 chk**：chk 是完整重启快照（实测 71 键 vs plt 约 25 键）、
> **float64**（plt 是 float32）、且**不受 `plot_var` 12 项白名单限制**。

## 4. 场景覆盖文件清单（只列名称与作用）

SNB 场景需要把若干 F90 文件放到
`<TREE>/source/Simulation/SimulationMain/<SimName>/` 覆盖树内同名文件。

| 文件 | 作用（性质） |
|---|---|
| `diff_advanceTherm.F90` | **核心**：电子热传导推进（SNB 多群非局域在此实现） |
| `Conductivity.F90` | Spitzer-Härm 电导 |
| `Driver_evolveFlash.F90` | 主时间推进循环（注意：**辐射调用可能被注释**，见坑位 P5） |
| `Grid_advanceDiffusion.F90` | 扩散线性求解接口 |
| `hy_uhd_DataReconstructNormalDir_PPM.F90` | 流体重构（PPM 法向） |
| `hy_uhd_dataReconstOneStep.F90` | 流体重构（单步） |
| `hy_uhd_getRiemannState.F90` | Riemann 求解器状态 |
| `hy_uhd_ragelike.F90` | RAGE-like 处理 |
| `mgd_qesh.F90` | 多群能量权重（**Makefile 必须列入**） |

配套还需：

- `Config`：声明 3T＋扩散＋MGD 依赖，并注册 SNB 诊断用的额外 `VARIABLE`；
- `Makefile`：`Simulation += Simulation_data.o mgd_qesh.o`；
- `Simulation_data.F90` / `Simulation_init.F90` / `Simulation_initBlock.F90`：场景初始化。

> ⚠️ **这些 F90 文件不在本分享目录内**（分享规则）。若你已有作者提供的包，
> 按上表放入单元即可；`Config` / `Makefile` / `Simulation_*` 可自行编写。

## 5. 编译必需的两个改动（性质说明，不含源码）

首次编译新 SNB 场景时可能遇到下面两类错误。**只描述需要改什么，不给代码**。

| 现象 | 需要的改动性质 |
|---|---|
| `Cannot open module file 'hy_uhd_slopelimiters.mod'` | 覆盖文件里引用的**模块名与当前 FLASH 树不一致**（树内实际模块名少了 `uhd_` 前缀）。需把引用改成树内真实模块名。 |
| 报错指向某表达式的续行 | 覆盖文件里**长表达式缺少 Fortran 续行符**，需按 Fortran 规则补齐。 |

其余已知的树级改动性质：

| 现象 | 需要的改动性质 |
|---|---|
| `Conductivity` 泛型不匹配 | 需按 `aniso` 开关分流到不同签名的 `Conductivity` 重载；若不匹配，**改调用方，不要改接口**。 |
| `hy_uhd` 里用到坡度限制器 | 需引用树内实际的坡度限制器模块（名字见上表）。 |

> **权威来源**：这些改动在"已知可用"的工作副本里已经打好。新场景**不要**直接用
> 作者原始包源（未打补丁），否则上述错误必然出现。

## 6. 已知限制（务必知情）

1. **1D 均匀各向同性前提**：SNB 分支只在 `NDIM==1` 且各向同性时生效；
   2D 分支是另一套代码路径，两者行为不完全一致。
2. **"限流器失效 → 守恒破坏"只在限流 SH 腿成立**：实测在 **SNB 场景**下
   `diff_eleFlMode` 是 **no-op** —— 各向同性电子分支的限流器调用与 SH 传导解
   **都被注释**（`:839`/`:847`），`fl_none` 与 `fl_harmonic` 六个物理量逐帧
   **逐位相同**（详见坑位 P1 更正块）。SNB 腿的热流由**多群非局域公式本身**
   约束，**不是**由限流器约束。
3. **网格细化会加剧启动瞬态**：界面越锐（dx 越小），启动越容易失稳；
   原作者的示例在 dx≈9.4 µm 下只能勉强推进，dx≈0.29 µm 下 8 ps 即中止，
   必须配合 `dtmax=2.0e-14`。
4. **辐射可能被静默关闭**：某些 SNB 覆盖文件把辐射推进调用注释掉了，
   par 里 `rt_useMGD=.true.` 也不生效（见坑位 P5 / `04_辐射开关.md`）。
5. **`plot_var` 上限 12**：超出项被静默忽略，不报错。
