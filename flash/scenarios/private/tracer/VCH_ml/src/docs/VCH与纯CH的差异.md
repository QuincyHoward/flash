## 1. 总体结论

- **F90 文件**：所有差异分属三类——(A) 几何/物质声明与分层逻辑（设计意图）；
  (B) 本次已恢复的格式/注释差异；(C) 溯源注释。**核心物理代码段（含
  killdivb 面变量清零块、物种质量分数填充、BDRY_VAR、3T 辐射初始化）
  两边逐行一致。**
- **par 文件**：319 个参数中，共同参数 308 个语义一致；非几何/物质差异
  仅 `plotFileIntervalStep` 一项，**已恢复为 2000**。
- **AMR 网格源码**：`Grid_markRefineDerefine.F90` / `Grid_markRefineSpecialized.F90`
  与 WSL FLASH4.8 paramesh 源逐字节一致（diff 为空）。

## 2. killdivb 代码段核对（用户指出的差异点）

`Simulation_initBlock.F90` 末尾 `#if NFACE_VARS > 0 ... #endif` 面变量清零块
（facexData/faceyData/facezData 三组 do 循环 + Grid_releaseBlkPtr）：

- REF 与 OURS **内容逐行一致**（含 `+K3D` 的 facezData k 循环上界、
  `NDIM>2` 守卫、释放调用）。
- 曾存在的差异仅在**入口 getBlkPtr 段的缩进**（OURS 顶格 vs REF 2 空格缩进）
  —— 已在生成器模板中恢复（见 §3）。

## 4. 保留的差异（几何/物质设置 —— 设计意图，不恢复）

### 4.1 Simulation_data.F90 / Simulation_init.F90
- REF：FOAM + targ/shld/samp/cham 声明（纯 CH，`sim_rhoTarg` 等参数）。
- OURS：cham/shld/samp/tar1/tar2/tar3/tar4/tar6 8 物种声明（tarX 块）。
- 属物质设置差异，全部保留。

### 4.2 Simulation_initBlock.F90
- REF：`bound1..bound5` 预计算边界 + targ/shld/samp 三分支。
- OURS：`bnd1..bnd13` 参数化边界（.par 运行时参数 sim_tarXRadius）+
  12 段 if/else-if 分层 + 8 物种物性分支。
- 属几何/物质设置差异，全部保留（这是 VCH 示踪层的核心设计）。
