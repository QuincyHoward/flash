## 1. 族定义与规模

**族判据（客观、不依赖命名）**：首行 60 字符、按 4×15 切成 `[ID, 类别名+标志, NR, NT]` 且
`NR/NT` 为 2–500 的整数，且**行数满足下面两条公式之一**。

| 样式 | 行数公式 | 带界行 | 实测文件数 |
|---|---|---|---|
| **多群** | `K × (2 + D)` | 有（30 字符） | 210 |
| **单群** | `1 + D` | 无 | 194 |

其中 `D = ⌈(NR + NT + NR·NT) / 4⌉`，`K` = 30 字符行的个数。

## 2. 记录结构（**第三轮更正**）

```
每条群记录（重复 K 次）：
  (1) 群表头    1 行, 60 字符 = [ ID(15) | 类别名+标志(15) | NR(15) | NT(15) ]
  (2) 带界行    1 行, 30 字符 = [ E_lo(15) | E_hi(15) ]        ← 仅多群有
  (3) 数据区    D 行, 60 字符 = log10(ρ[NR]) | log10(T[NT]) | log10(κ[NR·NT])
                每行恰 4 个 15 字符字段
```

**与旧版的三点差别**：

| 项 | 旧版（错） | 现行（对） |
|---|---|---|
| 每群组成 | 2 值带界行 + **4 值骨架行** + 数据区 | **群表头 + 带界行 + 数据区**（无骨架行） |
| 表头粒度 | 文件级 1 条 | **每群 1 条**（逐字重复） |
| 行数 | `1 + K·(2+D)` | 多群 `K·(2+D)`；单群 `1+D` |

**决定性证据**：`Ce.PLANCK` 非空 **2,240** 行 = `20 × 112`（不是 2,241）；30 字符行索引
`1, 113, 225 …` 间距恒 **112**；**索引 112 那一行逐字等于索引 0 的表头**。
旧版多算的 1 行 = "把每群表头当成文件级表头"；旧版"骨架行" = 下一条群记录的表头。

## 3. 群数语义：类别名后的标志字符

群表头第 2 字段写法为 **`<类别名> <标志>`**：

| 第 2 字段 | 语义 | 有无带界行 | 实测数 |
|---|---|---|---|
| `PLANCK M` / `ROSSELAND M` / `EPS M` | 多群 | 有 | 210 |
| `PLANCK 1` / `ROSSELAND 1` | 单群（gray） | 无 | 30 |
| **数值**（实测恒 `6.0`） | ZEFF 式单群 | 无 | 164 |

**`ZEFF` 式表头第 2 字段是常量 `6.0`，不是 Z。** 全部 164 个该样式文件此字段都是
`0.60000000E+01`；Al(Z=13) / Ce(Z=58) / D(Z=1) 取值相同 ⇒ **绝非原子序数**。

**群数不可从文件名推**：

- `opbe` 无后缀提示 → 实为 **40 群 Planck + 40 群 Rosseland + 1 张 ZEFF**；
- `Gd_op100PLANCK` 名含 `100` → K=100 ✓ 但网格 40×40（≠ `Gd100PLANCK` 的 30×50）；
- `Al_Planck_MULTI67.dat` 名含 `67` → 实测 `K = 32076/486 = 66`。

## 4. 坐标、网格与单位

**记录序**：`log10(ρ[NR]) → log10(T[NT]) → log10(κ[NR·NT])`。
**κ 段走向**：**外层 T、内层 ρ**（密度最快），`idx = (i_T−1)·NR + j_ρ`
`[S-SRC]` `matlab/outputMULTIOpacity.m:38-70`。
**ρ/T 网格是全局的**（每条群记录重复写同一份网格）。

### 4.1 输入卡 → 表内坐标（`doc/SNOP.MANUAL` 明文 `[S-L1]`）

| 卡参数 | 手册行 | 单位 | 表中呈现 |
|---|---|---|---|
| `RHO1` / `RHO2` | 34–37 | **g/cm³** | `log10(ρ[g/cm³])`，**无因子** |
| `T1` / `T2` | 38–41 | **keV** | `log10(T[eV])`，**×1000** |
| `X1` / `X2` | 42–44 | keV | 分群用，不入表 |
| `F0` / `F1` | 55–58 | eV | 自动分群限 |
| `FG(NG+1)` | 62 | **eV** | 各群带界行 |

### 4.2 逐位验证

| 材料 | 输入卡 | 表内反解 | 判定 |
|---|---|---|---|
| `mat_Ce` | `T1=1e-5, T2=5` keV；`RHO1=1e-4, RHO2=100` | `T = 0.01…5000 eV`；`ρ = 1e-4…100` | ✓ 精确 |
| `mat_Be-1.0` | `T1=1e-3, T2=100` keV；`RHO1=1e-6, RHO2=100` | `T = 1…1e5 eV`；`ρ = 1e-6…100` | ✓ 精确 |

> **旧版"T 轴 10× 因子悬案"作废**。真因是旧版把 κ 段误读为 T 网格。实际换算为 **×1000**（keV→eV），无残差。

## 6. 行宽与"缺陷行"

- **30 字符**：带界行（仅多群）。**60 字符**：群表头、数据行。
- **59 / 61 / 62 字符**：群表头宽度抖动（`Ce.ZEFF`、`Gd100ZEFF`、`Gd20ZEFF`、`Gd_op100ZEFF` 的表头为 **59** 字符；
  `opbe` 有 1 行 61 字符）。
- **处置**：按**列位置**切分（取前 60 列），**不要**用 `len(line) == 60` 筛选；宽度异常记警告不丢弃。
  普查中 251 个文件存在此类非 30/60 行，绝大多数即表头抖动。

## 7. `opbe` 的完整解释（旧版反例作废）

```
mat_Be-1.0/opbe   550,932 B

行 0     .. 4,479   40 条群记录，群表头 = 20203000  PLANCK M     (40 × 112 = 4,480)
行 4,480 .. 8,959   40 条群记录，群表头 = 20204000  ROSSELAND M  (40 × 112 = 4,480)
行 8,960 .. 9,070   1 张 ZEFF 式单群表（表头 20202000 + 110 行数据）  (1 + 110 = 111)
                                            -----------------------
                                            合计 = 9,071 行  ✓ 精确闭合
```

**结论**：`opbe` 是**三张表串联**，不是"80 群的单张表"，也不是"末群截断"。
同目录 `opbe.Planck`（4,480 行）/ `opbe.Rosseland`（4,480 行）/ `opbe.Zeff`（111 行）是其分表。
**判据更新**：不能只数带界行，**必须读每条群表头的类别名** —— 类别名会在文件中途改变。

## 8. 定稿解析器

见上位文档 §14.5.9 的 `read_multi_table()`（含 `_col15` / `_isnum` 辅助函数）。
要点：

1. 逐条读"群表头" → 由 `kind` 判断 `multi` / `single`；
2. **必须循环**（一个文件可含多张表，直到文件结束）；
3. 用 `len(vals) == NR+NT+NR·NT` 作唯一闭合判据；
4. 带界行判据用"整行去空白后 < 45 字符且前两字段为数值"，**不要**用 `len == 30`；
5. 反解 T 时记住表内已是 **eV**，输入卡 `T1/T2` 是 **keV**。
