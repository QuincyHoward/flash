### B.4 指南 §4.1 NAMELIST 参数（行 406–483）

`ngases`(≤10) / `izgas(i)`(≤54, 原子序数) / `atomwt(i)`(amu) / `fracsp(i)`(数分数) /
`ntemp` / `tplsma(1)`(起始温度 **eV**) / `dlgtmp`(默认 0.1，对数增量) /
`ndens` / `densnn`(起始**核子数密度 cm⁻³**) / `dlgden`(默认 0.1) /
`ntrad`(默认 0，辐射温度点数) / `trad`(eV) / `dlgtrd`(默认 0.1) /
`nptspg`(默认 5，每能群最小网格点) / `nfrqbb`(默认 5，每线心额外点) /
`dtheat`(默认 0.01) / `ngrups`(≤50) / `grupbd(i)`(ngrups+1 个边界，**eV**)

温度生成：`T_i = T_1 × 10^{(i-1)·dlgtmp}`（`isw(22)=0`，指南行 424，源码 2943–2951 印证）
密度生成：`n_i = n_1 × 10^{(i-1)·dlgden}`（`isw(23)=0`，指南行 435，源码 2997–3005 印证）

### B.5 指南 §2.3 关键物理量与单位（行 180–218）

- 比内能 $E$：J/g，相对中性原子基态；平均电荷态 $\langle Z\rangle=\sum_k f_k\sum_j j f_{jk}$
- 压力 $P=(1+\langle Z\rangle)n_{tot}k_BT$，代码转 dyne/cm²（1 J/cm³ = 10⁷ dyne/cm²）
- $k_B = 1.602\times10^{-19}$ J/eV；$C_V \approx [E(T+\Delta T)-E(T)]/(\Delta T\cdot T)$，$\Delta T=\text{dtheat}\cdot T$

### B.6 限制（指南 §8）

- 理想等离子体：$n_{tot}\le 10^{20}(T/\langle Z\rangle)^3$ cm⁻³；**不支持双温**（$T_e\neq T_i$）；$T\ge 10^4$ K
- 默认电离势仅 30 种元素：H He Li Be B C N O F Ne Na Mg Al Si P S Cl Ar K Ca Sc Ti V Cr Mn Fe Ni Cu Kr Xe
- `isw(8)=2` SESAME **未实现**（代码 `STOP`）

### D.3 ★ 计数公式 —— **逐文件精确验证通过**

**`.cn4` 行数（= `4e12.6` 记录数）公式**（由 C.5/C.6 推出）：
```
rec(n) = ceil(n/4)
lines_cn4 = 3                       # header, headr2, headr3  (各 1 行 a80)
          + 1                       # ngrups           (982 i12)
          + rec(ntemp)              # block 1  温度
          + rec(ndens)              # block 2  密度
          + rec(ntemp*ndens) * 12   # blocks 3–14 (zbar,dzdt,pion,pele,dpion_dT,dpele_dT,
                                    #              eion,eele,cvion,cvele,deion_dn,deele_dn)
          + rec(ngrups+1)           # block 15 能群边界
          + rec(ngrups*ntemp*ndens) * 3  # blocks 16–18 (Rosseland, Planck abs, Planck ems)
```
**实测验证（3/3 精确吻合）**：
| 文件 | ntemp×ndens×ngrups | 公式值 | 实际行数 | 判定 |
|------|--------------------|--------|----------|------|
| `eos_Gen.cn4` | 6×71×10 | **4506** | 4506 | ✔ |
| `al-imx-004.cn4` | 21×25×30 | **13423** | 13423 | ✔ |
| `polystyrene-imx-008.cn4` | 51×31×6 | **11895** | 11895 | ✔ |

**数值总数（非行数）公式**：
```
N_cn4 = ntemp + ndens + 12*ntemp*ndens + (ngrups+1) + 3*ngrups*ntemp*ndens
```
验证：`h-imx-1grp.cn4`（17,21,1）→ `2 + 17 + 21 + 12*357 + 2 + 3*357 = 5397`；
**实测 12 列定宽切分得 5395**，差 2 个 —— 原因是该文件有 89 处 e12.6 溢出
（见 H.2），修复后才闭合。**这是一条重要的实测反例**。

**`.cnr` 行数/数值公式**（由 C.8/C.9 推出，isw(8)=3）：
```
N_cnr = 2*ntemp*ndens + (ngrups+1) + 2*ngrups*ntemp*ndens
```
`ntrad` **不在 .cnr 头部存储**，须由计数守恒反解（对 isw(8)=1 旧格式）：
```

ntrad = rem / (2*ntemp*ndens)      # 不能整除 → 无法唯一切分
```

### H.2 ★ e12.6 **溢出缺陷**（实测确认，非常隐蔽）
源码格式 `991 format (4e12.6)` 只能容纳 `0.ddddddE±ee`（12 列）。
当指数为 **3 位数**时需 13 列 → **Fortran 运行时静默丢弃 `E`**：
```
0.638380E-140  (13 列，超出)  →  实际写出  0.638380-140   (12 列)
```
**实测证据**（本报告独立复核）：
- 文件 `matter++/Ionmix/h-imx-1grp.cn4`（ntemp=17, ndens=21, ngrups=1）
- 严格 12 列切分 token 总数 = **5395**
- 期望数值数 = `2 + 17 + 21 + 12*357 + 2 + 3*357` = **5397**
- 匹配 `^-?\d\.\d{1,6}[-+]\d{3}$` 的 token = **89** 个
- 修复规则（同仓库 `cn4_io.py` 的 `_PACKED_EXP_RE`）：`(\d\.\d{6})([-+]\d{3})` → `\1E\2`
- ★ 该缺陷使「数值个数守恒」在**未修复时不可能闭合**，是 `.cn4` 解析的**头号陷阱**
- 负值形态 `-1.00000-140`（12 列）同样丢 `E` —— 正则须允许**可选前导负号**

### H.10 `.cn4` 第 13/14 块（`deion_dn`/`deele_dn`）单位**源码自称不确定**
- 源码行 4715 / 4720 注释：`c ...    write out d(eion)/d(nion) (not sure)` / `(not sure)`
- 且写出量经 `condd = -6.242e18*avgatw/avgdro` 与 `densnn/tplsma**2` 换算
- 同仓库 `parsers/ionmix.py` 因此把这两场标 `unit_source="unknown"`，**拒绝代为断言**
- ⇒ 规格书中此两栏应明确标注「单位不确定」

### H.11 `.cn4` 头部「每行最多 5 个元素」
- `921 format (' atomic #s of gases: ',5i10)` —— 若 `ngases > 5`，第 2 行会**换行**
- `922 format (' relative fractions: ',1p5e10.2)` —— 同样
- 实测样本 `ngases` 都 ≤ 2，**未见 >5 的多行头部样本**（见 I 节）

### H.12 `4e12.6` 定点宽切分必须**按列**而非 `split()`
- 因负号吃掉前导空格，字段可**紧贴**（实测 `h-100grp-lte.cnr` 行 4 第 4 字段 `-.100000E+01`）
- 同仓库 `cn4_io.py::_parse_fixed_width` 与 `cnr_io.py` 都用 `range(0,len,12)` 定宽遍历
- 另：`D` 指数（Fortran 双精度）须替换为 `E`（解析器已处理 `.replace("D","E")`）

### H.13 尾随补零
- F2 族（Thermos dat / SNOP 输出）「有凑满每行 4 字段的习惯」→ 文件尾可能有 ≤4 个补零
- 解析器 `multi_opacity.py` 行 212–219/259–269 显式把尾部 ≤4 数值记为 `raw_tail`，
  **并计入 expected**，否则会误报 `count_mismatch`
- ⇒ 任何自行实现解析器者必须处理尾部 padding

### H.14 命名拼写陷阱
- 标签是 **`ROSSLAN`**（5+3 字母）而非 `ROSSELAND`，也有 `PLANCK 1`/`PLANCK M`/`PS M`/`EPS M`
- 宽松正则 `ROS+LAN?D?` 会**匹配不到 `ROSSELAND`**（`S+` 后直接要 `LAN`，中间有 `E`）—— 实测踩过

### H.15 `opbe` 是**多 KIND 串联**文件
- `opbe.inhalt` 声明 4 个表号 `NPLA/NROSS/NEPS/NZ`
- ⇒ 单个 `opbe` 文件由 **4 个不同 KIND 的表**串联而成，读到第 2 类表时不能沿用第 1 类的 KIND
- 解析器 `multi_opacity.py::parse()` 只返回第一张表，并**警告其余表被丢弃**
