## 1. 格式布局与计数公式

实测（`mat_B/B.data.txt`，**12524 行 × 10 列**，制表符分隔）：

```
0	0	 0.00000000e+00	 0.00000000e+00	 3.53712002e-53	 8.86026323e-54	 2.65109369e-53	...
1	0	 2.34000000e-05	 0.00000000e+00	 3.53712002e-53	 2.30141416e+00	-2.30141482e+00	...
```

- **列 1、2（col0/col1）是两个索引**（`i`、`j`，实测为递增整数），其后为材料参数与 EOS/不透明度量。
- **列数取众数**：统计各行数值个数，取众数 `ncol` 作为列宽；`ncol < 3` 即报错。
- **偏离行报错**：数值个数 ≠ `ncol` 的行**不静默丢弃**，抛 `CountMismatch`（附前 10 个异常行号）。
- 分隔策略：先按制表符切；`<2` 格时回退空白切分；逐格走 L2 数值提取。
- 计数守恒：`n_numbers_seen = n_numbers_expected = 行数 × ncol`（结构自洽，但**列语义无公式**）。

## 2. 物理量与单位（含 uk/uv 标记）——诚实登记型

控制字典 `feos_tabdata` 族条目摘录（**全部列整体 unknown，绝无例外**）：

| 字段 | 意义 | 单位 | 来源类型 | 标记 |
|---|---|---|---|---|
| `*`（col0..colN） | All columns（colN naming; no local column-name doc） | `unknown` | none | **uk, uv** |

字典理由（照录）：colN 占位列名——本地无任何一级列名文档（仅有中间产物草稿提及，**不作依据**）——语义待人工核查，不猜。解析器 `unit_source = "none (列语义无本地文档)"`。

## 4. 陷阱与 unknown 清单

1. **20 手册 §11 条目 #3（必须复述）**：F4 `feos_tabdata` 的全部列——**本地无该导出的列名文档** → 单位标 `unknown`，不猜测（`feos_tabdata.py:76,80`）。
2. **col0/col1 是索引不是物理量**：解析器明确标注，避免被下游误当物理字段绘图。
3. **偏离行是硬错误**：众数列宽之外的行抛 `CountMismatch`——不静默丢行、不猜测对齐。
4. **可联 `.301` 兄弟文件交叉核对**：本表数值可用同族 `.301`（见 `feos_native.md` 的 `find_sibling_301` 与交叉校验方法，如 `mat_B/B.301`）逐值核对，但**这只校验数值对应关系，不赋予列语义**——列名仍待人工核查。
5. 本地检索结论：该导出格式仅有中间产物草稿提及（不作依据），无一级列名文档——**绝不因文件名/数值量级猜测物理含义**。
