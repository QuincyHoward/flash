## 0. 体系总览：为什么不需要 N×N 个转换器

```
任意格式 A ──parse──▶ ParsedTable（统一容器：axes/fields/field_units/field_log10/field_shape）
                          │
                          ▼ convert(table, out, target=T)
                    ConvertTarget 注册表（KIND 门控 can_write）
                          │
                          ▼
任意格式 B ──write_x──▶ 磁盘
```

5 个已注册目标：`cn4`（默认）/ `multi_opacity`(F2) / `hyades_eos`(F3) / `multi_inverted_eos`(F1) / `h5`。
cn4 ↔ MULTI 族（F1/F2/F3）的转换**不是无损往返**：F1 的自变量是 `(rho, de)` 而非
`(rho, Te)`，所以任何一条跨 `(rho,de)` 与 `(rho,Te)` 基的路径都要经过一次
**网格重参数化**（反演或正演反演），见 §2/§3。

## 1. cn4 → F1（multi_inverted_eos）：四步链

实现：`writers_multi.write_multi_inverted_eos_from_cn4(eos_table, out_path, *, n_de=60, de_axis=None)`。

### 1.1 第一步：轴适配 nion → rho

cn4 的自变量轴是**离子数密度** `nion (cm^-3)`，F1 需要质量密度 `rho (g/cm3)`：

$$\rho_j = \frac{n_{ion,j}\cdot \langle A\rangle}{N_A}$$

- `⟨A⟩ = avgatw` 必须显式给出（cn4 头部 atomwt 或调用方传入），**不猜**；
- `N_A = 6.02214076e23`（`config.py` 单一来源）；
- 实现校验：cn4 的 rho 派生场沿 Te 方向应为常值（`rtol=1e-9`），否则轴替换不成立、报错
  （`invert_eos._check_rho_const`）。

### 1.2 第二步：单位换算（cn4 → MULTI 惯例）

| 量 | cn4 原生 | F1 惯例 | 换算 |
|---|---|---|---|
| P | J/cm³ | Mbar | $P_{\rm Mbar} = P_{\rm J/cm^3} \times 10^{-5}$ |
| E | J/g | Mbar·cm³/g | $E_{\rm Mcg} = E_{\rm J/g} \times 10^{-5}$（1 Mbar·cm³/g = 10⁵ J/g） |
| T | eV | 文件写 Kelvin | $T_{\rm K} = T_{\rm eV} / {\tt EV\_PER\_K}$（写出时） |

### 1.3 第三步：正演反演 (rho,Te) → (rho,de)

核心难点：cn4 给的是 $P(\rho, T), E(\rho, T)$，F1 要的是 $P(\rho, d_e), T(\rho, d_e)$。
实现 `invert_eos.to_de_grid(table, de_targets, value_fields=("P",), log_value=("P",), extrapolate="edge")`。

**de 口径（2026-11-14 用户裁定）**：

$$d_e \equiv E_{\rm total} = e_{\rm ion} + e_{\rm ele}$$

cn4（IONMIX）能量零点在冷态（$T{=}0$ 时 $E\equiv 0$），即 $E_c \equiv 0$，
故 `no_e0` 布局严格等价文献口径 $E - E_c$（SESAME 301−306），**不引入假冷曲线**。

**目标 de 轴**：缺省 log10 等距 `n_de=60` 点，范围 $[E_{\min+},\ E_{\max}]$
（取换算后 $E>0$ 的值域；`E ≤ 0` 值少于 2 个时报错）。

**逐密度列算法**（对每个 rho 列 $j$）：
1. 横坐标 $x_i = \log_{10} E_{i,j}$，纵坐标 $y_i = \log_{10} T_{i,j}$（$T$ 即源 Te 轴，沿列复制）；
2. 反解温度：$\log_{10} T^*(d) = {\tt interp}(\log_{10} d;\ x,\ y)$；
3. **用同一插值位置**对压力插值：$\log_{10} P^*(d) = {\tt interp}(\log_{10} d;\ x,\ \log_{10} P_{\cdot,j})$，
   再 $P^* = 10^{\log_{10} P^*}$——P 与 T 在 log-log 空间共用同一横轴插值，保证 $P/T$ 自洽；
4. 越界处理 `extrapolate="edge"`：目标 $d$ 超出该列 $[x_{\min}, x_{\max}]$ 时取**端点常值延拓**
   （记入 notes；F1 文件不允许 NaN，生成整表必须 edge）。`extrapolate="nan"` 则与
   反演方向（§3）一致地置 NaN。

### 1.4 第四步：写出 F1 文件（`write_multi_inverted_eos`）

- 头行 4 数（fmt15 = `%15.8e` 定宽）：`table_id / 0.0 / nr / ne`；
- body 展平顺序：`rho 轴(nr) + de 轴(ne) + P(ne×nr, T-major) + T_K(ne×nr) [+ e0_cold]`；
- cn4 来源恒写 **no_e0** 布局（无 `e0_cold` 场）；每行 4 个数值；
- 换行默认 LF（MULTI 族实测），可覆盖。

## 2. cn4 → F2（multi_opacity）

实现：`writers_multi.write_multi_opacity_from_cn4(opac_table, out_path, *, avgatw, label=None)`。

1. **轴适配**：同 §1.1（`cn4_opac_to_rho_base`，保留 `group_bounds` eV 与 `n_groups`）；
2. **值域守卫**：κ 线性值（cm²/g）中任何 $\kappa \le 0$ → 报错（log10 存储不可行）；
3. **存储变换**：$\kappa_{\rm stored} = \log_{10} \kappa$——F2 文件内 κ **本身就是 log10 值**
   （`field_log10=True`），写出**不再取一次 log10**（双取 log10 是历史头号坑）；
4. **标签映射**（`_CN4_OPAC_LABEL`）：`kind=ROSSELAND → "ROSSLAN M"`（f2=4.0）、
   `PLANCK → "PLANCK M"`（f2=7.0）；其他 kind 必须显式传 `label`；
5. **写出**（`write_multi_opacity`）：多群 = `ng` 个独立子表串联，每子表：
   头行 `id + 标签 + nr + nt`（多群再加群边界行 `lo, hi`，eV）→ `log10(rho)` 轴 →
   `log10(Te)` 轴 → κ 段（**T-major 展平**，每行 4 列）。

群边界说明：cn4 的群边界（如 0.1–1e5 eV 6 群）与 MULTI 惯例文件（C_1G/20G/100G）
通常**不同**——群数不同的转换只做"转换 + 绘图"，不做数值对比（裁定见
`parsers/test/test_multi/README.md`）。

## 3. F1 → (rho, Te)：反演（to_Te_grid）

实现：`invert_eos.to_Te_grid(table, Te_targets, *, fields=("P","E","T"), log_value=("P",))`。
这是 §1.3 的**逆操作**，也是 F1 与统一网格/HDF5/h5 目标之间的必经步骤。

**目标 Te 轴约定**（`writers_multi._invert_to_te` / hyades `invert=True` 共用）：
源 T 场正区间 $[\min T, \max T]$、**点数与 ne 相同**、log10 等距。

**逐密度列算法**（对每个 rho 列 $j$）：
1. 横坐标 $x_i = \log_{10} T_{i,j}$，纵坐标 $y_i = \log_{10} d_{e,i}$；
2. 求 $d_e^*(T) = {\tt interp}(\log_{10} T_q;\ x,\ y)$——注意这里插的是 **de 本身**（log 空间）；
3. 压力在 log10 空间插值再幂回：$P^* = 10^{{\tt interp}(d_e^*;\ y,\ \log_{10} P_{\cdot,j})}$；
   能量 E（可有负值）与 T 线性插值；
4. 越界 → **NaN，不静默外插**（与 §1.3 的 edge 相反：反演方向用于分析，宁可 NaN 不可造假值）；
   每场 NaN 计数写入 `InversionResult.notes`，`coverage` 属性给出覆盖率。

## 4. → F3（hyades_eos）：T 写 keV、行数恒等式

实现：`writers_multi.write_hyades_eos(table, out_path, *, zbar, abar, rho0, comment, invert=False)`。

- **行数恒等式**：$L = 2 + n_r + n_t + 2\,n_r n_t$（头 2 行 + 两轴 + P/E 两块）；
- **温度单位**：$T_{\rm keV} = T_{\rm eV} \times {\tt KEV\_PER\_EV}\ (=10^{-3})$——F3 文件 T 以 keV 写出
  （实测 qeos 文件存 $\log_{10} T_{\rm keV}$，单位链 log10(T_keV)×1e3 → eV 的三方差证见
  `parsers/test/test_multi/README.md` Si 节）；
- body：`[nr, nt] + rho + T_keV + P + E`（P/E 均 **T-major** 展平），每行 **5** 列 fmt15；
- 头 2 行：comment + `id / zbar / abar / rho0 / L`；
- 换行默认 **CRLF**（hyades MATLAB 风格实测），MULTI 族为 LF；
- 源表是 (rho,de) 基时必须 `invert=True`：先经 §3 反演到 (rho,Te) 再写。

## 5. → cn4（默认目标，跨族枢纽）

实现：`writers_cn4.write_cn4_single(table, out_path, *, izgas=None, fracsp=None, atomwt=None)`，
内部走 `parsers.cn4_io.parsed_tables_to_cn4(..., allow_foreign=True)`。

- 表内没有的二维场/不透明度块一律 **NaN 占位**（不写 0——0 是合法物理值）；
- 组成信息**不猜**：`izgas` 必须显式给出，`fracsp` 仅单元素时默认 `[1.0]`；
- 单温总 EOS 由组装层 **1:1 均分**到 ion/ele 槽（保证 $P = P_i + P_e$、$E = E_i + E_e$ 守恒）；
- **单位不换算**（cn4 = J/cm³、J/g），换算责任在调用方；
- 多表材料（独立不透明度子表）走 `parsers.cn4_io.convert_foreign_to_cn4`。

## 7. MULTI 族物理量词典 —— 逐量定义、公式与原始矩阵实例

> 本节回答"每个物理量是什么、单位是什么、从原始数据矩阵的哪个位置怎么算"。
> 所有实例数值均由解析器实测提取（2026-11-15，样例见各小节）。

### 7.1 F1 反演 EOS（multi_inverted_eos）

**两种布局**（`detect_layout` 自动判别）：

| 布局 | payload 段顺序 | 计数公式 | 实例 |
|---|---|---|---|
| `with_e0`（含冷能） | `rho(nr) de(ne) e0(nr) P(nr·ne) T_K(nr·ne)` | `4+2·nr+ne+2·nr·ne` | `AL_eos` = 9978 |
| `no_e0`（无冷能） | `rho(nr) de(ne) P(nr·ne) T_K(nr·ne)` | `4+2·nr+ne+2·nr·ne − nr` | `AU_eosd` = 4770 |

**逐量定义**：

| 物理量 | 文件内位置 | 单位（文件） | 定义与公式 |
|---|---|---|---|
| `table_id` | 头行第 1 数 | — | 8 位 SESAME 号：`xxxx{类型位}nnn`，第 5 位（右数第 4 位）是类型位（1=EOS / 3=Planck / 4=Rosseland / 5=emissivity / 6=ZEFF） |
| `rho0` | 头行第 2 数 | — | **未用占位**（解析器丢弃；AL_eos 值 2.7 与 rho 轴末值 27.0 无函数关系） |
| `D` / `rho` 密度 | 第 1 段，nr 个 | g/cm³ | 质量密度轴（MULTI 文档记作 D）；升序，可含 0.0 端点 |
| `de` 比能轴 | 第 2 段，ne 个 | Mbar·cm³/g | **冷曲线之上比内能** $d_e = E - E_c$——F1 的自变量；注意它**不是温度**，T 是因变量 |
| `e0` / `e0_cold` 冷能 | 第 3 段（仅 with_e0），nr 个 | Mbar·cm³/g | 冷曲线比内能 $E_c(\rho_j)$，**沿 rho 一维**（与 de 无关） |
| `P` 压力 | 第 4 段，nr·ne 个 | Mbar | 二维场，**T-major 展平**（de 慢变、rho 快变）：扁平索引 $= i_{de}\cdot nr + j_{rho}$ |
| `T` 温度 | 第 5 段，nr·ne 个 | **Kelvin**（文件） | 因变量场 $T(\rho, d_e)$；解析器读入 ×`EV_PER_K` 转 eV，写出 ÷`EV_PER_K` 还原 K |
| `E` 总比内能 | **解析器派生**，非文件段 | Mbar·cm³/g | with_e0：$E_{i,j} = d_{e,i} + E_{c,j}$；no_e0：$E_{i,j} = d_{e,i}$（notes 注明"以 de 为基准"） |

**单位换算链**（与 cn4/F3 互转用）：
$$P_{\rm J/cm^3} = P_{\rm Mbar}\times 10^{5},\quad P_{\rm dyne/cm^2} = P_{\rm Mbar}\times 10^{11}$$
$$E_{\rm J/g} = E_{\rm Mbar\cdot cm^3/g}\times 10^{5},\quad E_{\rm erg/g} = E_{\rm Mbar\cdot cm^3/g}\times 10^{12}$$

**原始矩阵实例**：`matter++/mat_Al-1.0/AL_eos`（铝，with_e0，nr=66 × ne=74）。

原文头行（逐字）：

```
     37181000    .27000000E+01  .66000000E+02  .74000000E+02
```

→ `table_id=37181000`（SESAME 3718 + 类型位 1）、`rho0=2.7`（未用）、`nr=66`、`ne=74`。

实测提取（`F1.parse` 后）：

| 量 | 实测值 |
|---|---|
| rho 轴 | 66 点：`0.0 → 27.0` g/cm³（前 4 点 0.0, 3e-6, 5e-6, 1.3e-5） |
| de 轴 | 74 点：`0.0 → 75799.923` Mbar·cm³/g（前 4 点 0.0, 4.11e-4, 1.55e-3, 3.88e-3） |
| e0_cold | 前 4 点 `0.101122, 0.101122, 0.100367, 0.099161`，末点 `3.5736` |
| E 闭合校验 | $E_{i{=}0,\,j} = d_{e,0} + E_{c,j} = 0 + e0_j$ ✓（0.101122 = 0.101122） |
| 中点示例 | $i_{de}{=}37,\ j_{rho}{=}33$：$d_e{=}0.0471,\ \rho{=}1.2150$ → **P = 0.0108 Mbar，T = 0.533 eV，E = 0.0618**（扁平索引 $37\times66+33=2475$；且 E = de+e0 = 0.0618 精确闭合） |

⚠️ 低温端点注意：de=0 行的 P/T 为 `0.0 / −0.0`（冷态定义），属合法物理值，**不是缺失**。

#### 冷能 e0_cold 专项核查（2026-11-15）：形状、来源与 no_e0 省略的正当性

**① 形状澄清——不是矩阵，是一维向量。** `e0_cold` 形状 `(nr,)`（`parsers/multi_inverted_eos.py:251`）：
冷曲线比内能 $E_c(\rho_j)$，**每个密度一个值，与 de 无关**。它不是二维场，与 P/T/E（nr·ne）根本不同维度。

**② cn4 来源不是"设为全 0"，而是整段省略。** `write_multi_inverted_eos_from_cn4` 恒写 `no_e0`
布局——文件里**没有 e0 数据段**（计数式少 nr 个数）。写出器逻辑：

```python
# writers_multi.py:241-242
if "e0_cold" in table.fields:      # cn4 来源的 ParsedTable 没有 e0_cold 字段
    body += list(table.fields["e0_cold"])   # → 永不执行，落 no_e0
```

写全 0 反而是错的：no_e0 布局下 $E_c$ 隐含为 0，若显式写 `e0=全0`，语义会变成
"de 是绝对能量、冷态能量恒为 0"的**假冷曲线声明**——与 with_e0 消费方按 $E = d_e + E_c$
重建总能的约定冲突。省略才是无歧义表达。

**③ 两条路径的冷能来源完全不同：**

| 路径 | 冷能怎么来 |
|---|---|
| cn4 → F1（no_e0） | **不需要算**。IONMIX 能量零点定义在冷态（T=0 时 E≡0），cn4 表内 $E_{total}=e_{ion}+e_{ele}$ 本身就是相对冷态的能量，即已等于文献口径 $E-E_c$（SESAME 301−306 造表时已扣）。`de ≡ E_total`，冷曲线信息"内嵌"在数据里 |
| with_e0 文件（AL_eos 等） | **上游造表者提供，本仓库只透传**。MATLAB/matter++ 管线从 SESAME 301 表取 0 K 等温线（冷曲线）内能在 rho 网格上采样得 $E_c(\rho_j)$；in-file 注释原文："de[ne] 能量（与**冷能量**的差距）"、"e0[nr] 冷能量（密度对应的冷能量列表）"（SESAME docx，见 03_注释证据通道 §265-266）。解析器原样读出（AL_eos：首点 0.101122、末点 3.5736），转换写出时原样回写（`writers_multi.py:241`），**从不自己计算或拟合冷曲线** |

**④ no_e0 省略有原始文件先例，不是本仓库自创：**

| 原始文件 | 布局 | 证据 |
|---|---|---|
| `mat_Au-1.0/AU_eosd`（金） | **no_e0**：2 个同表头块串联，每块 payload = 4770 = rho+de+P+T（无 e0 段） | `test/parsers/test_multi_inverted_eos.py:82-84` 以它为解析契约；20 手册 §2 布局表 `AU_eosd → 4770` |
| `mat_Be-1.0/BE_eos_i` | 变体：no_e0 基础上尾部多 2 个未声明零 | `detect_layout` docstring 明文记载；尾部多余 1..nr 个数必须**显式标注**、不许静默吸收 |
| `mat_Al-1.0/AL_eos` 等 | with_e0（含 e0 段，计数 9978） | §7.1 实例 |

正因为原始文件族中**两种布局都真实存在**，解析器才有 `detect_layout(nr, ne, n_payload)`
（`multi_inverted_eos.py:81`）这个按计数公式自动判别双布局的函数——若所有文件都带 e0，
该逻辑无需存在。两公式恒差 `nr`（nr≥2），精确解唯一，消费端不存在歧义风险。

**结论**：SESAME docx 规格虽只写 with_e0 公式 `4+2*nr+ne+2*nr*ne`，但上游交付数据中
AU_eosd 就是省略版；cn4 转换写 no_e0 同时满足**格式先例**（与 AU_eosd 一致、消费端双布局
均认）与**语义自洽**（de 的定义即"与冷能量的差距"，cn4 的 E 恰好就是该差距）。

### 7.2 F2 不透明度 / Zeff / EPS（multi_opacity）

**每子表布局**（多群 = ng 个子表串联，每子表自带网格）：

```
头行:  table_id | 标签或类型枚举 f2 | nr | nt     （%15.7e×4 定宽）
[多群再加一行群边界: lo_eV  hi_eV]
第 1 段: log10(rho) —— nr 个
第 2 段: log10(T)   —— nt 个
第 3 段: log10(载荷) —— nr·nt 个，T-major 展平（索引 = i_T·nr + j_rho）
```

**逐量定义**：

| 物理量 | 文件层存储 | ParsedTable 还原 | 公式 |
|---|---|---|---|
| `rho` | **log10(ρ)** | `axes["rho"] = 10^x`（线性 g/cm³），`axis_log10=True` 仅作**溯源标记**（"文件层是 log10"） | $\rho = 10^{x}$ |
| `T` | log10(T) | `axes["Te"]` 线性 eV；keV 声明 ×`1e3`；Kelvin 变体 ×`EV_PER_K` | $T_{\rm eV} = 10^{x}\,(\times 10^{3}\ if\ {\rm keV})$ |
| `kappa`（PLANCK/ROSSELAND/MUGROUP） | **log10(κ)**，`field_log10=True` | 场值保持 log10 不动；消费侧 $10^x$ 还原 | $\kappa_{\rm lin}\,[{\rm cm^2/g}] = 10^{\kappa_{\rm stored}}$ |
| `Z`（ZEFF） | **log10(zbar)**（2026-11-14 45 元素族校准裁定） | `field_log10=True` | $zbar = 10^{x}$；**哨兵 $x=-10$ = log10(1e-10) = 无电离**；$10^x$ ≈ 核电荷数 |
| `Z2`（ZEFF2，"Av Sq Free"） | log10(⟨Z²⟩) | Thermos 无样本，未校准（不适用裁定） | ⟨Z²⟩ 与 ⟨Z⟩（TOPS FAQ Q1/Q7）见 20 手册 §6.2 |
| `eps`（EMISSIVITY） | log10(ε) | 同 κ | MULTI = Kirchhoff 绑定 η=κ·B（SNOP.MANUAL NEPS） |
| `nonlte`（NONLTE） | 因子表 | `field_units="1"` 无量纲 | 非 LTE 修正因子 |
| `f2_or_label` | 头行第 2 数/文本 | `table.f2_or_label` | 类型枚举：4.0=ROSSELAND、6.0=ZEFF、7.0=PLANCK；文本标签 `PLANCK 1`/`PS M`/`EPS M` |

**原始矩阵实例**：`matter++/mat_CELIA/C_AN.PLANCK`（CH，灰度 Planck，20×20，计数 444 闭合）。

| 量 | 实测值 |
|---|---|
| 头行 | `1 / PLANCK 1 / 20 / 20`（id=1、f2 标签"PLANCK 1"、nr=nt=20） |
| rho 轴（文件层 log10） | `-6 → 2`；还原线性 `1e-6 → 100` g/cm³（几何序列，比值 $10^{8/19}\approx2.638$） |
